ICE WORLD 3D - Unity package
=============================
Requires: Unity 2021.3 LTS, 2022.3 LTS or Unity 6. Built-in or URP both work. No extra packages needed.

HOW TO RUN
1. Unity Hub > New project > "3D" template (any render pipeline) > Create.
2. Close Unity (optional), then copy the "Scripts" folder from this ZIP into your project's Assets folder
   (so you have Assets/Scripts/IceGame.cs, Bootstrap.cs, Inp.cs, GameAudio.cs). Or drag the folder into the Project window.
3. Open any scene (SampleScene is fine) and press PLAY. The game builds itself - no objects to add.

CONTROLS
Arrow keys / A D = move lane | Up / W / Space = jump | Down / S = slide | Esc / P = pause
Touch: swipe left, right, up (jump) or down (slide).

BUILD
File > Build Settings > Add Open Scenes > choose platform (PC, Android, iOS) > Build.

FEATURES
5 levels + Endless, 3 hearts, coins, gems (goal 10), stars, combo score, shield / magnet / speed-boost power-ups,
spikes, arches, moving ice blocks, falling icicles, blizzard events, snow, shop upgrades (shield time, magnet time,
extra heart, double jump), achievements, top-5 scores, level select, pause, settings (music, sfx, quality), saved progress.
